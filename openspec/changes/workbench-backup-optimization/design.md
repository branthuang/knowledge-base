## Context

前四阶段已实现全部核心知识存储、双路混合搜索与 AI 闭环回流。
本阶段（M5）为知识库系统补齐管理总览、创作体验与数据主权安全能力：
1. 工作台资产统计看板与动态流转；
2. 编辑器 AI 一键润色优化与差异对比；
3. 全量数据无损导出备份、校验恢复及单篇 Markdown 导出。

## Goals / Non-Goals

**Goals:**
- 实现工作台 5 项宏观指标聚合计算与动态流转聚合接口（最近编辑、待整理 AI 沉淀草稿、近期搜索历史、高频标签）。
- 实现编辑器 AI 一键润色（“简洁易懂”模式），严格遵循“防篡改（保留代码/数据不变）、防幻觉（不编造事实）、必须人工对比确认”准则。
- 实现标准 ZIP 全量备份包导出与校验导入恢复，包含校验和（SHA-256）与清单（`manifest.json`）。
- 实现单篇知识无损导出为标准 GitHub Flavored Markdown。
- 自动化测试与全量回归验收 100% 通过。

**Non-Goals:**
- 本阶段不实现复杂多分支协同冲突消解算法。
- 本阶段不实现跨云多租户备份托管（保持个人私有化部署定位）。

## Decisions

1. **工作台统计性能考量**：
   - 采用轻量高效的单次 SQL `count` / `select` 聚合查询，无锁执行，响应时间控制在 50ms 内。
2. **AI 优化防篡改约束（Safety Prompting）**：
   - Prompt 明确强制：
     1. 代码块逐字原样保留；
     2. 数字、URL、变量名、技术结论严禁修改；
     3. 优化后解析为 BlockItem 树返回，不直接覆盖数据库，由前端展示双栏差异对比。
3. **备份包格式设计（Self-contained Standard ZIP）**：
   - `manifest.json`: 记录元数据、生成时间戳、统计计数与 `data.json` 的 SHA-256 校验和；
   - `data.json`: 完整包含 `categories`, `tags`, `knowledge_items`, `knowledge_tags`, `sources`；
   - 导入恢复时校验签名，使用幂等式导入，并自动触发派生向量索引构建。
