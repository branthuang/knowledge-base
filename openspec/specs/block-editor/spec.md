# block-editor Specification

## Overview
块级编辑器（Block Editor）是知识内容创作的核心组件。系统采用基于块的数据模型存储内容，支持富文本排版、代码、表格、图片、附件及结构化交互，实现细粒度块级索引与复用。

## Requirements

### Requirement: 结构化块数据模型
编辑器中的所有内容必须表示为具备唯一标识和独立属性的块对象集合（Blocks JSON）。

#### Scenario: 块数据存储结构
- **WHEN** 编辑器内容序列化为 JSON
- **THEN** 每个块包含：
  - `id`: 块唯一 UUID
  - `type`: 块类型标识符
  - `properties`: 块的样式与配置属性
  - `content`: 块内的文本或结构化数据
  - `children`: （可选）子块数组

### Requirement: MVP 基础文本与排版块
编辑器必须支持主流富文本排版语义，包括段落、层级标题、引用、提示信息与分割线。

#### Scenario: 文本与标题编辑
- **WHEN** 用户在编辑器中输入正文或选择标题样式
- **THEN** 系统支持渲染及保存以下块类型：
  - `paragraph`: 普通文本，支持加粗、斜体、删除线、颜色、行内代码、超链接
  - `heading`: 支持 H1、H2、H3、H4 层级标题
  - `quote`: 引用块，用于引用外部内容
  - `callout`: 提示卡片块，支持不同强调色彩与图标
  - `divider`: 水平分割线块

### Requirement: 列表与待办块
编辑器必须支持无序列表、有序列表以及交互式待办事项列表。

#### Scenario: 待办状态切换
- **WHEN** 用户在阅读或编辑模式下点击待办项（Todo block）的选择框
- **THEN** 该项状态在未完成与已完成之间切换，并持久化保存。

### Requirement: 代码块与语法高亮
系统必须提供支持多编程语言语法高亮与便捷复制代码块能力。

#### Scenario: 插入与复制代码
- **WHEN** 用户选择代码块类型并选择编程语言（如 TypeScript, Python, SQL 等）
- **THEN** 编辑器提供语言标签选择、实时语法高亮，并提供一键复制全部代码按钮。

### Requirement: 表格块
编辑器必须支持基础二维表格操作。

#### Scenario: 表格编辑与行列管理
- **WHEN** 用户插入表格块
- **THEN** 用户可动态增加/删除行与列、调整对齐方式并在单元格内输入富文本。

### Requirement: 媒体与附件块管理
编辑器必须支持图片拖拽/粘贴即时上传，以及通用附件的上传与下载。

#### Scenario: 粘贴图片自动上传
- **WHEN** 用户在编辑器内粘贴或拖拽图片文件
- **THEN** 系统自动将图片上传至存储服务，生成存储 URL，并在编辑器中渲染为图片块，支持设置说明文字和缩放比例。

#### Scenario: 上传文件附件
- **WHEN** 用户插入附件块并上传本地文件
- **THEN** 系统记录文件名、大小、MIME 类型及存储地址，在阅读模式下提供安全下载入口。

### Requirement: 编辑器交互快捷能力
系统必须支持斜杠命令（"/"）、拖拽排序以及外部内容粘贴转换。

#### Scenario: 斜杠命令呼出面板
- **WHEN** 用户在空行输入 "/" 字符
- **THEN** 编辑器弹出块类型选择菜单，支持键盘快捷过滤并快速插入目标块。

#### Scenario: 粘贴 Markdown 与 HTML
- **WHEN** 用户从剪贴板粘贴外部 Markdown 文本或 HTML 片段
- **THEN** 编辑器自动解析排版语义并转换生成对应的多类型结构化块。

### Requirement: 后续阶段扩展块定义（P1/P2）
系统架构必须具备可扩展性，为 P1 阶段的 Mermaid 图表块和 Canvas 画板块预留挂载规范。

#### Scenario: Mermaid 图表块渲染（P1 规划）
- **WHEN** 启用 Mermaid 扩展块且用户输入流程图或时序图文本语法
- **THEN** 编辑器实时预览编译后的矢量图形，并保持源文本可编辑。

#### Scenario: Canvas 自由画板嵌入（P1 规划）
- **WHEN** 启用画板块
- **THEN** 支持嵌入自由涂鸦、形状连接、便签白板画板，并保存图元数据与预览图。
